# Aptitude Mastery Plan

## Overview

This study plan is designed to build a strong foundation in **Quantitative Aptitude**, **Logical Reasoning**, and **Verbal Ability** over a period of **12 weeks**. It is suitable for campus placements, competitive examinations, and aptitude-based interviews.

---

# Daily Study Schedule

| Activity              | Recommended Duration |
| --------------------- | -------------------: |
| Learn Concepts        |        45–60 minutes |
| Solve Guided Examples |           20 minutes |
| Practice Questions    |           60 minutes |
| Review Errors         |           20 minutes |
| Timed Practice        |           20 minutes |

> **Recommended Study Time:** Approximately 2.5–3 hours per day. If time is limited, aim for at least 90 minutes while maintaining the same sequence.

# Recommended Learning Process

For every topic, follow the same structured approach:

1. Learn the underlying concepts.
2. Solve worked examples.
3. Practice basic problems.
4. Progress to intermediate questions.
5. Attempt advanced problems.
6. Solve timed practice sets.
7. Review mistakes and record them in an error log.

2. Identify incorrect and skipped questions.

4. Revise weak areas within 24 hours.
5. Reattempt incorrect questions after several days.

# Best Practices

* Study consistently rather than relying on intensive short-term preparation.
* Prioritize conceptual understanding before learning shortcuts.
* Maintain an error log throughout the preparation period.
* Practice under timed conditions to improve speed.
* Analyze every mock test thoroughly.
* Focus on improving accuracy before attempting to increase speed.
* Revise previously studied topics every week.

---

# Expected Outcomes

By the end of this study plan, you should be able to:

* Solve aptitude problems efficiently and accurately.
* Perform well in campus placement assessments.
* Approach competitive examination aptitude sections with confidence.
* Identify recurring mistakes and systematically eliminate them through revision.

Consistent effort over the full 12-week period will produce significantly better results than irregular, high-intensity study sessions.
